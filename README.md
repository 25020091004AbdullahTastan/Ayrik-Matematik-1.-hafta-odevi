# Ayrik-Matematik-1.-hafta-odevi
Ayrık Matematik dersinin 1. hafta ödevini Word üzerinde MathType kullanımımı pekiştirecek şekilde tamamlamış bulunmaktayım. Bu ödev kapsamında mantık alanında aşağıdaki konuları öğrendim:
✔️ Önerme kavramı, doğruluk değeri ve bileşik önermeler 
✔️ Bir önermenin tersi, karşıtı ve karşıt tersi 
✔️ Mantıksal eşdeğerlilik, totoloji ve doğruluk tabloları
Çözdüğüm örnekleri aşağıya bıraktım.
